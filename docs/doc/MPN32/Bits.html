    Shifts and bits #

    • shiftLeft a n is a * 2ⁿ: the limbs of a shifted left by n % 32 bits into fresh limbs above n / 32 zero limbs, by main's WordArray.lshiftW (or copyW for whole limbs), which reads a where it is.
    • shiftRight a n is a / 2ⁿ: the limbs of a from n / 32 on shifted right by n % 32 bits into fresh limbs, by WordArray.rshiftW (or copyW).
    • shrLimbs, a right shift in place from the top limb down, divides the interpolation values of the Toom methods by powers of 2 and is the exact division by 2, 4 and 8.
    • land, lor and xor of arrays, limb by limb, by main's WordArray.bitW.

    Both results are trimmed.

    Shifts #

    source
    @[inline]
    def MPN.W32.shlStep (s : UInt64) (v c : UInt32) :
    UInt32 × UInt32

    Limb v shifted left by s < 32 bits, plus the carry c < 2^s; the bits above go up. The carry out depends on v only, not on c, which keeps the loop free of a dependency chain: c lands in the s low bits, which the shift leaves zero, so the sum doesn't wrap.
