    Multiplication by a limb #

    The linear primitives of multiplication, after GMP's mpn_mul_1 and mpn_addmul_1, by main's generic passes (MPN.MulLimbW), which update an array in place with one exclusivity check and USize indices. Neither trims its result.

    • addMul1 r off a x adds a x to the limbs of r from off on, and returns the carry limb.
    • addMul1SetW r off arr st n x adds the n limbs of arr from st on times x to r from off on and stores the carry at off + n, inside the fold: the step of the schoolbook loops, where that limb is still zero. addMul1Set is it on a slice, and addMul1SetPre on the first n limbs of a slice, read from its array without a slice object.
    • mul1 and mulRow multiply into zeros.

    Each pass needs the arrays to fit in a USize, which every array in memory does; otherwise it writes the value of its specification with writeNat, which never happens.
