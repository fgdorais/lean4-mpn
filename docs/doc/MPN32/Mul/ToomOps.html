    The operations of the Karatsuba and Toom methods #

    The instance of MPN.Toom.ToomOps on UInt32Array. The linear operations are main's generic kernels (MPN.Toom.Kernels), in place on the windows, and so is the middle term of Karatsuba's method (MPN.Toom.Mid). The base cases are the kernels of this library on its slices, which return new arrays: each applies its kernel and copies the result into the window (put). Each checks the bounds its kernel needs; otherwise it writes the value of its specification with LimbArray.writeNat, which never happens.
