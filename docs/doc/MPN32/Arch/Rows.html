    Schoolbook multiplication by rows into wide accumulators #

    rowsMul a b adds the rows aᵢ b into an array of UInt64 accumulators, one per limb of the product, and propagates the carries in one pass at the end. Within a row, accumulator i + j receives the low half of aᵢ b_j and the high half of aᵢ b_{j-1}: no carry goes from one product to the next, so the C compiler vectorizes the row (two products per instruction with SSE2, four with AVX2), where the columns of Comba's method (Mul.Comba) need a sum across the vector after each column. Each accumulator gains less than 2³³ per row, so fewer than 2³¹ rows cannot overflow it.

    The value of the accumulators is accVal, the limbs with base 2³² but each up to 2⁶⁴ - 1.
