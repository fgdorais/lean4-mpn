    Limb arrays with USize bounds #

    The tooling of main64's flat-array FFT on 32-bit limbs: the instance limbArray32 of main's LimbArray, whose valAt is the value of a range of limbs; USlice, a region of an array with USize bounds; foldUInPlace, the in-place loop; and foldUInPlace2, the in-place loop that reads other windows of the array it writes. Their @[csimp] lemmas run lean4-scalar-arrays' folds in their place. The rest of the library works on the library's slices and MPN.toNat.

                        In-place loops #

                        foldUInPlace n f arr rs hr j b replaces limbs rs + j to rs + n - 1 of arr while threading an accumulator: limb rs + j holding x becomes (f j hj x b).1, and (f j hj x b).2 is the next accumulator. Its definition is a loop of usets, which checks that arr is exclusive at every store; its implementation, through foldUInPlaceThen, makes arr exclusive once and then stores without checks. That is safe because f only sees the limbs, never the array: anything f reads, even another reference to the same array, is the object from before the loop.
