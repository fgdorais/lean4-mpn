    Configuration #

    Config collects the size thresholds, in limbs, at which the arithmetic switches algorithms. The algorithms take a Config as a parameter, and the library's own MPN.config is built by mpn_config% from the options mpn.w32.f, one for each field f, set when the library is compiled (MPN.ConfigOptions). The package's lakefile.lean sets them from the options of a project's require, keyed by the fields of Config with the prefix w32_, for example options = { w32_mulKaratsuba = "48" } (see the README). Options that are not set keep the defaults of Config. Each threshold carries the proof of the condition its algorithm needs, so an invalid value is rejected when the library is compiled.

    The defaults were measured with lake exe tune on an AMD Ryzen 5 5600X, except where GMP chooses an algorithm on modern platforms whatever the size: the reciprocal steps of division and Zimmermann's square root, which the defaults take always, like GMP. Running lake exe tune on the target machine prints the thresholds for that machine and the options that set them.

      The size of both operands together from which the schoolbook product adds rows into wide accumulators instead of Comba's method.

    • mulCombaW : Nat

      The size of the shorter operand from which Comba's method adds whole products in its columns.

    • sqrRows : Nat

      The size from which the schoolbook square adds rows into wide accumulators instead of Comba's method.

    • sqrBasecase : Nat

      The size from which squaring uses the schoolbook square instead of multiplying.

    • four_le_divDC : 4 ≤ self.divDC

      Blocks of half the divisor need at least 4 limbs, so that the recursion has two.

    • div1Recip : Nat

      The size from which division by a normalized limb takes Möller and Granlund's steps with a precomputed reciprocal instead of the hardware divider: always, like GMP's mpn_divrem_1.

    • div32Recip : Nat

      The size of a normalized divisor from which schoolbook division estimates the quotient limbs by GMP's 3-by-2 steps with a precomputed reciprocal instead of the hardware divider: always, like GMP's mpn_sbpi1_div_qr.

    • div2Rows : Nat

      The size of the divisor from which schoolbook division takes two quotient limbs per pass, by one multiply-subtract pass with two rows (Schoolbook.divLoop2In): always, as measured on Zen 3.

    • div1Unnorm : Nat

      The size from which division by an unnormalized limb takes the steps with a precomputed reciprocal of the divisor normalized by a shift, with the dividend shifted, instead of the hardware divider: always, like GMP's mpn_divrem_1.

    • gcdHalf : Nat

      The size of the smaller number from which the greatest common divisor uses half-gcd.

    • strDC : Nat

      The size from which decimal strings are written by divide and conquer.

    • parseDC : Nat

      The size of the result, in limbs, from which decimal strings are read by divide and conquer.
