    Configuration #

    Config collects the size thresholds, in limbs, at which the arithmetic switches algorithms. The algorithms take a Config as a parameter, and the library's own MPN.config is built by mpn_config% from the options mpn.w64.f, one for each field f, set when the library is compiled (MPN.ConfigOptions). The package's lakefile.lean sets them from the options of a project's require, keyed by the fields of Config with the prefix w64_, for example options = { w64_mulKaratsuba = "48" } (see the README). Options that are not set keep the defaults of Config. Each threshold carries the proof of the condition its algorithm needs, so an invalid value is rejected when the library is compiled.

    The defaults were measured on an AMD Ryzen 5 5600X, except where GMP chooses an algorithm on modern platforms whatever the size: the reciprocal steps of division and Zimmermann's square root, which the defaults take always, like GMP. lake exe tune prints the thresholds for the machine it runs on and the options that set them.

    • div1Recip : Nat

      The size from which division by a normalized limb takes Möller and Granlund's steps with a precomputed reciprocal instead of the hardware divider: always, like GMP's mpn_divrem_1.

    • div1Unnorm : Nat

      The size from which division by an unnormalized limb takes the steps with a precomputed reciprocal of the divisor normalized by a shift, with the dividend shifted, instead of the hardware divider: always, like GMP's mpn_divrem_1.

    • div32Recip : Nat

      The size of the divisor from which schoolbook division estimates the quotient limbs by GMP's 3-by-2 step with a precomputed reciprocal instead of the hardware divider: always, like GMP's mpn_sbpi1_div_qr.

    • div2Rows : Nat

      The size of the divisor from which schoolbook division takes two quotient limbs per pass, by one multiply-subtract pass with two rows (Schoolbook.divLoop2In), as measured on Zen 3: below it, the fixed cost of the two-limb estimate outweighs the pass it saves.

    • sqrtRemRenorm : Nat

      The size of the root, in limbs, from which the square root with its remainder takes the remainder of Zimmermann's recursion, renormalized by a product by a word, instead of x - s², when the operand needs a shift (Bridge.sqrtRemZ); as measured on Zen 3, where the passes of the renormalization cost more than the square below it.

    • gcdHalf : Nat

      The size of the smaller number from which the greatest common divisor uses half-gcd.

    • strDC : Nat

      The size from which decimal strings are written by divide and conquer.

    • parseDC : Nat

      The size of the result, in limbs, from which decimal strings are read by divide and conquer, as tune64 measures it on an Apple M2 (576–640, with leaves of 1200 digits) since the powers without their zero limbs and the base case in place; about 600 on an x86 cloud machine.
