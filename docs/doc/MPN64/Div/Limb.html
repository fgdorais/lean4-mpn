    Division by a limb #

    divRem1 r a d writes the limbs of a / d into r and returns a % d, like GMP's mpn_divrem_1, by main's WordArray.divRem1W: from the top limb down, by UInt64.div2, or by Möller and Granlund's step with a precomputed reciprocal, checked, from config.div1Recip limbs for a normalized d and from config.div1Unnorm limbs for another, normalized by a shift.

      def MPN.W64.divRem1With (t tu : USize) (r a : ScalarArray.UInt64Array.USlice) (d : UInt64) :
      ScalarArray.UInt64Array × UInt64

      Writes the limbs of a / d into r and returns a % d, on the first min r.size a.size limbs, like GMP's mpn_divrem_1. It requires 0 < d. It takes the steps with the reciprocal from t limbs for a normalized d, and from tu limbs for another, normalized by a shift.
