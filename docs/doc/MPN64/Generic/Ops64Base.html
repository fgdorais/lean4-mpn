    The operations of the 64-bit instance of NatOps #

    ops64With div runs the base-generic algorithms on whole arrays of 64-bit limbs with the operations of MPN.Num and the division div: the schoolbook division for the base-generic divide-and-conquer division (ops64B, MPN.Div.DC), and Num.divMod for the others (ops64, MPN.Generic.Ops64). Those are proved for arrays of fewer than USize.size limbs, which every array that fits in memory has, but which the logical model of arrays does not know; so each operation checks that its operands are small enough (fits, on constants that are machine words), and otherwise computes with Nat (ofNatN). That branch cannot run: it would need arrays of more than 2³¹ limbs on a 32-bit platform or 2⁶² on a 64-bit one.

          Trimming #

          source
          def MPN.W64.trimA (x : ScalarArray.UInt64Array) :
          ScalarArray.UInt64Array

          x without its zero limbs on top, but at least one limb: the operations of MPN.Num leave such limbs, and the generic algorithms decide by sizes. It is main's WordArray.trimTo 1, which pops them, in place when x is not shared, which the fresh results of MPN.Num never are; it is x itself when its top limb is nonzero.
