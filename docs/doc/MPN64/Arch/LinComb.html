    The kernel of Lehmer's step #

    mulSubMul x y a b is a x - b y in one pass over the limbs, main's LinComb.mulSubMul on UInt64Array, like GMP's mpn_hgcd_mul_matrix1_vector, or none when it is negative: each limb adds a xᵢ, subtracts b yᵢ, and carries a signed word (sval) to the next (msWord). mulAddMul x y a b is a x + b y in the same way (maWord), for the entries of the matrices of half-gcd. The steps and their values are the instance linComb64 of main's LinCombOps.
