    Schoolbook multiplication #

    Like GMP's mpn functions, these write their result into the limbs of the slice r, in place when its array is not shared. All the slices have USize bounds, so the loops index with USize.

    • mul1 r a x c writes the low limbs of a * x + c and returns the high limb, like mpn_mul_1;
    • addMul1 r a x c adds a * x + c to the limbs of r and returns the carry out, like mpn_addmul_1;

    both on the first min r.size a.size limbs, and

    • mulBasecase r a b writes the a.size + b.size limbs of a * b, like mpn_mul_basecase. It requires 0 < b.size and a.size + b.size ≤ r.size, and leaves r unchanged otherwise.

    mulBasecase writes the first row with mul1, then adds the rows two at a time, like GMP's mpn_addmul_2: one pass over a adds a (b[i] + β b[i + 1]) (addMul2Loop), with two carries, so that each limb of the result is read and written once for two products of limbs. The pass runs as an in-place program in lean4-scalar-arrays' experimental inplace notation, which keeps both carries unboxed in the loop; an odd last row is a pass of addMul1Loop.
