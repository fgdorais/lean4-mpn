    Schoolbook squaring #

    sqrBasecase r a writes the 2 a.size limbs of a * a into the slice r, like GMP's mpn_sqr_basecase. It computes each cross product aᵢ aⱼ with i < j once, by rows into r, then doubles them and adds the squares aᵢ² of the diagonal in one pass, since a² = Σ aᵢ² 2^(128 i) + 2 Σ_{i < j} aᵢ aⱼ 2^(64 (i + j)). It requires 0 < a.size and 2 a.size ≤ r.size, and leaves r unchanged otherwise.
