    The square root of a double limb #

    sqrt2W hi lo is ⌊√N⌋ for N = hi β + lo, by Newton's iteration on limbs, the base case of Zimmermann's recursion like GMP's mpn_sqrtrem2. The iteration starts from 2ᵉ with e = ⌊log₂ N / 2⌋ + 1, just above the root, so that it converges quadratically from the first step; each step is the average of x and N / x by one div2.
