    Polynomials #

    Coefficient lists of natural numbers and their values, polyVal x cs = c₀ + x c₁ + x² c₂ + ⋯ by Horner's rule: values of sums, products (the convolution of the coefficients, with a bound on them) and of the even and odd parts, which the FFT assembles its products with.

    source
    def MPN.polyVal (x : Nat) :
    List Nat → Nat

    c₀ + x c₁ + x² c₂ + ⋯.

    Equations
    • MPN.polyVal x [] = 0
    • MPN.polyVal x (c :: cs) = c + x * MPN.polyVal x cs
