    The base-two logarithm of a word #

    Lean's runtime computes UInt64.log2 and UInt32.log2 by a loop over the bits, one step per bit: 63 dependent steps for the largest words. log2Fast is a binary search instead, six steps of a shift and a comparison for 64 bits and five for 32, without a loop, in portable code. @[csimp] makes the compiler use it in place of log2 in every module that imports this one.

    source
    theorem MPN.log2_div_add {n k : Nat} (h : 2 ^ k ≤ n) :
    n.log2 = (n / 2 ^ k).log2 + k

    Halving the search: log₂ n = log₂ (n / 2ᵏ) + k when 2ᵏ ≤ n.
