    Division by a limb, for limbs of any width #

    divRem1W writes the limbs of a / d into a window of r and returns a % d, like GMP's mpn_divrem_1, from the top limb down (divLoop): each step divides the remainder so far, followed by the next limb, by d. The remainder stays below d, so this two-limb number is below d β and its quotient fits in a limb.

    The step is div2Rem (divStep), or for a normalized d, with its top bit set, Möller and Granlund's 2-by-1 step with the precomputed reciprocal ⌊(β² - 1) / d⌋ - β (div21, GMP's udiv_qr_2by1), whose one double product and two corrections cost less than a hardware divider. div21 checks its result exactly, q d + r = c β + x with r < d, by one more double product off the dependency chain, so that neither the reciprocal nor the error bound of the step needs a proof. A failed check gives the remainder d, which makes every later check fail too, so that the division checks the last remainder once and divides again with div2Rem if it is not below d, which never happens.

    For an unnormalized d, the same steps divide a 2ˢ by d 2ˢ, whose top bit is set, as in GMP: each limb of a 2ˢ is formed from two limbs of a as the loop goes (divLoopSh), and the remainder is shifted back (divRem1U). Each branch has its own threshold.
