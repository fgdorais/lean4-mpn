    Shifts of windows of limbs #

    lshiftW r ro a ao n s writes the n limbs of a from ao, shifted left by 0 < s < w bits, into r from ro and returns the bits out of the top, like GMP's mpn_lshift; rshiftW shifts right and returns the bits out of the bottom, like mpn_rshift; and copyW copies, for shifts by whole limbs. Each is one in-place fold over the window of r (foldThen), whose step reads a by uget; r and a are different arrays, since a second reference to r would copy it.

                Right shifts in place #

                rshDown shifts a window of an array right in place, from its top limb down, carrying the low bits of each limb into the limb below. Each step reads only the limb it writes, so that the array, held once, is updated in place, where rshiftW, which reads another array, would copy it.

                Limbs ro to ro + j - 1 of w with c 2ʷʲ above, shifted right by s bits in place, from limb ro + j - 1 down; c holds the s low bits of the limb above. It requires 0 < s < w.
