    NatOps on arrays of limbs, for limbs of any width #

    opsA k O cfg div hdiv is the instance of NatOps on arrays of w-bit limbs at base 2ʷ that runs the base-generic algorithms on a width's own operations: O gives the products, the sum and the difference (ArrayOps, specified below the sizes of fitsU), and div the division; the rest is shared: lo and hi copy their limbs out (extract), shl is shlBits, join is joinW, le is ltA, and mulMod is the wrapped product Dispatch.mulModW with the thresholds cfg. The results of the products, the sum, the difference, shl and mulMod are trimmed to k limbs, so that the next products see no zero limbs on top, and past the sizes of fitsU every operation computes from the values, which never happens.

      Type

      A width's operations on arrays, specified below the sizes that fitsU decides.

      • mul : A → A → A
      • val_mul (x y : A) : fitsU (LimbArray.size x + LimbArray.size y + 1) = true → vA (self.mul x y) = vA x * vA y
      • sqr : A → A
      • val_sqr (x : A) : fitsU (2 * LimbArray.size x + 1) = true → vA (self.sqr x) = vA x * vA x
      • add : A → A → A
      • val_add (x y : A) : fitsU (LimbArray.size x + LimbArray.size y + 1) = true → vA (self.add x y) = vA x + vA y
      • sub : A → A → A
      • val_sub (x y : A) : fitsU (LimbArray.size x + LimbArray.size y + 1) = true → vA y ≤ vA x → vA (self.sub x y) = vA x - vA y
