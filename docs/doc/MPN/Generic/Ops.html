    MPN.NatOps

    Whole-number operations at any base #

    NatOps α bundles the operations on numbers represented by α that the base-generic algorithms (MPN.Generic) use, each with its specification on values: numbers of size x limbs at a base B, with products, sums, differences, comparison, low and high parts, shifts by whole limbs, powers of B, and a slow division to fall back on. Nothing here depends on the width of a limb, so an algorithm written and proved over NatOps serves 32-bit limbs today and 64-bit limbs later with only a new instance.

    structure MPN.NatOps (α : Type) :
    Type

    Whole-number operations at base B on a representation α, with their values.

    • B : Nat

      The base, 2³² for 32-bit limbs.

    • one_lt_B : 1 < self.B
    • val : α → Nat

      The value of a representation.

    • size : α → Nat

      The number of limbs, an upper bound on the length of the value.

    • val_lt (x : α) : self.val x < self.B ^ self.size x
    • mul : α → α → α
    • val_mul (x y : α) : self.val (self.mul x y) = self.val x * self.val y
    • sqr : α → α

      x², which squaring computes faster than mul x x.

    • val_sqr (x : α) : self.val (self.sqr x) = self.val x * self.val x
    • add : α → α → α
    • val_add (x y : α) : self.val (self.add x y) = self.val x + self.val y
    • sub : α → α → α

      x - y, specified when y ≤ x.

    • val_sub (x y : α) : self.val y ≤ self.val x → self.val (self.sub x y) = self.val x - self.val y
    • le : α → α → Bool

      Whether x ≤ y.

    • le_iff (x y : α) : self.le x y = true ↔ self.val x ≤ self.val y
    • lo : Nat → α → α

      The low k limbs: x % Bᵏ.

    • val_lo (k : Nat) (x : α) : self.val (self.lo k x) = self.val x % self.B ^ k
    • hi : Nat → α → α

      The limbs from k on: x / Bᵏ.

    • val_hi (k : Nat) (x : α) : self.val (self.hi k x) = self.val x / self.B ^ k
    • size_hi (k : Nat) (x : α) : self.size (self.hi k x) = self.size x - k
    • shl : Nat → α → α

      x Bᵏ.

    • val_shl (k : Nat) (x : α) : self.val (self.shl k x) = self.val x * self.B ^ k
    • join : Nat → α → α → α

      x Bᵏ + y % Bᵏ: x above the low k limbs of y, which an array builds in one pass.

    • val_join (k : Nat) (x y : α) : self.val (self.join k x y) = self.val x * self.B ^ k + self.val y % self.B ^ k
    • pow : Nat → α

      Bᵏ.

    • val_pow (k : Nat) : self.val (self.pow k) = self.B ^ k
    • one : α
    • val_one : self.val self.one = 1
    • mulModSize : Nat → Nat

      The size of the modulus of mulMod n, at least n: mulMod n x y is x y modulo B ^ mulModSize n - 1.

    • le_mulModSize (n : Nat) : n ≤ self.mulModSize n
    • mulMod : Nat → α → α → α

      x y modulo B ^ mulModSize n - 1, up to a multiple of it, which a wrapped product, like the FFT's, computes faster than mul.

    • val_mulMod (n : Nat) (x y : α) : self.val (self.mulMod n x y) % (self.B ^ self.mulModSize n - 1) = self.val x * self.val y % (self.B ^ self.mulModSize n - 1)
    • divRem : α → α → α × α

      (x / y, x % y) by a slow algorithm, the fallback of the fast ones.

    • val_divRem (x y : α) : self.val y ≠ 0 → self.val (self.divRem x y).fst = self.val x / self.val y ∧ self.val (self.divRem x y).snd = self.val x % self.val y
