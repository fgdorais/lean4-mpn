    Square root, at any base #

    NatOps.sqrtRemAux base T N n computes ⌊√N⌋ and the remainder N - ⌊√N⌋² for N < B²ⁿ with B²ⁿ ≤ 4 N, by Zimmermann's Karatsuba square root, like GMP's mpn_dc_sqrtrem: with B' = Bˡ for l = ⌊n / 2⌋, N = N₁ B'² + a₁ B' + a₀, the root t of N₁ and its remainder recursively, then the quotient q and the remainder u of (N₁ - t²) B' + a₁ by 2 t give the root t B' + q or one less (karatsuba_sqrt); the division is by t, whose top limb is at least B / 2, and its quotient is halved. Up to T limbs, or at one, the instance's base takes over; the instance normalizes by 4ᶜ before calling. The facts about Nat.sqrt here serve both libraries. From main64's MPN.Sqrt, at any even base.

    theorem MPN.karatsuba_sqrt {B N' a₁ a₀ t q u : Nat} (ht : t = N'.sqrt) (ha₁ : a₁ < B) (ha₀ : a₀ < B) (hs : B ≤ 2 * t) (hq : q = ((N' - t * t) * B + a₁) / (2 * t)) (hu : u = ((N' - t * t) * B + a₁) % (2 * t)) :
    (q * q ≤ u * B + a₀ → (N' * B * B + a₁ * B + a₀).sqrt = t * B + q ∧ N' * B * B + a₁ * B + a₀ - (t * B + q) * (t * B + q) = u * B + a₀ - q * q) ∧ (u * B + a₀ < q * q → (N' * B * B + a₁ * B + a₀).sqrt = t * B + q - 1 ∧ N' * B * B + a₁ * B + a₀ - (t * B + q - 1) * (t * B + q - 1) = u * B + a₀ + (2 * (t * B + q) - 1) - q * q ∧ 1 ≤ q ∧ q * q ≤ u * B + a₀ + (2 * (t * B + q) - 1))

    Zimmermann's Karatsuba square root step, as in GMP's mpn_dc_sqrtrem: for N = N' B² + a₁ B + a₀ with a₁, a₀ < B and B ≤ 2 s', where s' = ⌊√N'⌋, the quotient q and the remainder u of (N' - s'²) B + a₁ by 2 s' give s = s' B + q and T = u B + a₀, and then ⌊√N⌋ is s with the remainder T - q² when q² ≤ T, and s - 1 with the remainder T + 2 s - 1 - q² otherwise.
