    Decimal strings by divide and conquer, at any base #

    NatOps.toDec writes the decimal digits of a number in O(M(n) log n) operations with a subquadratic division, after GMP's mpn_get_str: with the powers p_j = 10^(2ʲ), it divides by the largest p_j ≤ x, writes the quotient, and then the remainder with exactly 2ʲ digits, splitting it by p_{j-1} in the same way (padDec). Numbers of at most T limbs go to the instance's own conversion, which only has to be correct (base), and are padded with zeros. The specification is Nat.toDigits 10, the digits of Nat.repr.

            def MPN.NatOps.padDec {α : Type} (o : NatOps α) (base : α → String) (T : Nat) :
            List α → α → String

            The 2ᵏ decimal digits of x < 10^(2ᵏ), with leading zeros, for the powers ps below 10^(2ᵏ): the digits of the quotient and of the remainder by the top power, recursively, and base below T limbs.

            Equations
            • o.padDec base T [] x✝ = MPN.padZerosStr 1 (base x✝)

                  Reading digits #

                  fromDec reads digits after GMP's mpn_set_str: the high digits times a power 10^(2ʲ) plus the low 2ʲ digits, recursively. The power 10^(2ʲ) ends with 2ʲ zero bits, nearly a third of its limbs at base 2ʷ, so each power is kept as p' Bᶻ with those z zero limbs off (IsPowsZ): the products by p' are smaller, and so are the squares that compute the powers.
