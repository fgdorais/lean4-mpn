    The transforms over residue operations #

    The transforms of length 2ᵐ modulo F = 2^(w n) + 1, on 2ᵐ residues in consecutive windows of n + 1 limbs of one array, in place, with one scratch window, for limbs of any width w. They need only a few operations on windows, given with their specifications by WinOps: the sum and the difference of two residues, each into a third window or both in one pass into two windows, and the product of one by a power of two. The root of unity is 2^σ with σ 2ᵐ = 2 w n, so that 2^(σ 2ᵐ⁻¹) = 2^(w n) ≡ -1.

    • The forward transform, by decimation in frequency, replaces each pair (x, y) of the two halves by (x + y, (x - y) 2^(σ j)), then transforms each half with the root 2^(2 σ). It leaves Σᵢ xᵢ 2^(σ i rev p) at position p, where rev reverses the m bits of p.
    • The inverse transform, by decimation in time, takes its input in that order: it transforms each half, then replaces each pair (x, y) by (x + y 2^(-σ j), x - y 2^(-σ j)). Since 2^(-σ j) ≡ -2^(w n - σ j), the multiplications are by powers less than 2^(w n), with the signs swapped. It leaves Σₚ uₚ 2^((2 w n - σ) rev p l) at position l.

    Composed, with the pointwise products in between, the bit reversals cancel. main32 and main64 instantiate WinOps with their residue operations on arrays of 32-bit and 64-bit limbs.

        The residue operations modulo 2^(w n) + 1 on windows of n + 1 limbs of arrays of limbs, with their specifications: each writes the window at d, leaves the other limbs as they are, and reads windows disjoint from it or equal to it.

        • subMod : A → Nat → Nat → Nat → Nat → A

          (x - y) % F into the window at d: subMod arr n d x y.

        • addMod : A → Nat → Nat → Nat → Nat → A

          (x + y) % F into the window at d: addMod arr n d x y.

        • mulPow2 : A → Nat → Nat → Nat → Nat → A

          t 2ᵉ % F into the window at d: mulPow2 arr n d t e.
