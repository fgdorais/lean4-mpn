    FFT multiplication #

    Schönhage–Strassen multiplication, like GMP's mpn_mul_fft: a and b are cut into K = 2ᵏ pieces, whose products are the coefficients of a convolution. The convolution is computed modulo the Fermat number F = 2ᴺ + 1, large enough to hold each coefficient, by a discrete Fourier transform of length K with the root of unity ω = 2^(2N / K): multiplying by a power of ω is a shift, so the transforms need no products, and the K pointwise products are products of N bits.

    This first part, on natural numbers with the sums of MPN.Sum and the congruences of MPN.NatMod, is the inversion of the transform modulo F. The transform of length K inverts because its geometric sums 1 + x + ⋯ + x^(K - 1) are the products (1 + x) (1 + x²) ⋯ (1 + x^(K / 2)), one of whose factors vanishes when x is a power of ω other than 1, since ω^(K / 2) ≡ -1. No division and no primality are needed. The residues modulo F and the transform itself depend on the width of a limb, and are in each library's own FFT modules.

    Geometric sums of length 2ᵏ #

    source
    theorem MPN.FFT.sumRange_pow_two_succ (x k : Nat) :
    sumRange (fun (x_1 : Nat) => x ^ x_1) (2 ^ (k + 1)) = sumRange (fun (x_1 : Nat) => x ^ x_1) (2 ^ k) * (1 + x ^ 2 ^ k)

    1 + x + ⋯ + x^(2ᵏ⁺¹ - 1) = (1 + x + ⋯ + x^(2ᵏ - 1)) (1 + x^(2ᵏ)).

    source
    theorem MPN.FFT.sumRange_pow_two_mod {x k s F : Nat} (hs : s < k) (hx : (x ^ 2 ^ s + 1) % F = 0) :
    sumRange (fun (x_1 : Nat) => x ^ x_1) (2 ^ k) % F = 0

    When some x^(2ˢ), s < k, is -1 modulo F, the geometric sum of length 2ᵏ vanishes.

    Roots of unity #

    source
    theorem MPN.FFT.exists_two_pow_mul_odd (d : Nat) (hd : 0 < d) :
    ∃ (v : Nat), ∃ (u : Nat), d = 2 ^ v * u ∧ u % 2 = 1

    Every positive d is 2ᵛ u with u odd.

    source
    theorem MPN.FFT.exists_pow_two_neg_one {w F k d : Nat} (hw : (w ^ 2 ^ (k - 1) + 1) % F = 0) (hd : 0 < d) (hdk : d < 2 ^ k) :
    ∃ (s : Nat), s < k ∧ ((w ^ d) ^ 2 ^ s + 1) % F = 0

    When ω^(2ᵏ⁻¹) ≡ -1 modulo F, every power ωᵈ with 0 < d < 2ᵏ has a power (ωᵈ)^(2ˢ), s < k, that is -1 modulo F: with d = 2ᵛ u, u odd, take s = k - 1 - v.

    theorem MPN.FFT.inverse_mod (w w' F k : Nat) (hk : 1 ≤ k) (hw : (w ^ 2 ^ (k - 1) + 1) % F = 0) (hww : w * w' % F = 1 % F) (z : Nat → Nat) (l : Nat) (hl : l < 2 ^ k) :
    sumRange (fun (j : Nat) => sumRange (fun (i : Nat) => z i * w ^ (i * j)) (2 ^ k) * w' ^ (j * l)) (2 ^ k) % F = 2 ^ k * z l % F

    The inversion of the transform: with ω^(2ᵏ⁻¹) ≡ -1 and ω ω' ≡ 1 modulo F, transforming z by ω and the result by ω' gives 2ᵏ z, modulo F.
