    Residues modulo 2^(w n) + 1 #

    The FFT works modulo the Fermat number F = 2^(w n) + 1, on residues of n + 1 limbs of w bits whose value is less than F, so that the top limb is 0 or 1, and 1 only for 2^(w n) ≡ -1. They are windows of one flat array: each function takes the array, n and the offsets of the windows it reads and the one it writes, and returns the new array, through the in-place fold fold2Then of WordFolds, so that the array is never shared.

    Since 2^(w n) ≡ -1, the value L + 2^(w n) H of a window is L - H modulo F, which is how the results are reduced: the top limb is subtracted from the others, and when that borrows, 1 is added, by loops that stop as soon as the carry or the borrow is zero.

    The operations with Nat offsets, which check their bounds (subModG, addModG, mulPow2G), are those of WinOps, for the transforms.

                              Writes t 2ᵉ % F into the window at d, for a residue t in the window at t, disjoint from it, and e < w n. With e = w q + b, the limbs of t above n - q wrap around negated, since 2^(w n) ≡ -1: they are subtracted from zero into the low q limbs, the others are copied above them less the borrow and the top limb of t, and 1 is added when that borrows. The shift by b bits, when b ≠ 0, follows in place, then a reduction.
