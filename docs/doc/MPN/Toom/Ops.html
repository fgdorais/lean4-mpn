    The operations of the Karatsuba and Toom methods #

    The methods of MPN.Toom write a product into a window of the array of the result, in place, and compute the values at their points in new arrays, changed in place by linear passes. ToomOps gives those passes, the product and the square below the thresholds, and the middle term of Karatsuba's method, with their specifications on LimbArray.valAt. A window is len limbs of an array from limb o on; an operation writes one window of its first array and reads windows of the others. main32 and main64 instantiate the class with their kernels on 32-bit and 64-bit limbs.

    The specifications only assume that the window written is within its array. The kernels of the branches need more, such as indices that fit in a USize; their instances check it and otherwise write the value of the specification with LimbArray.writeNat, which never happens.

      Type

      The in-place operations of the Karatsuba and Toom methods on arrays of limbs, with their specifications. D is the value of the window written before the operation and S the value of the window read.

      • w_ge : 32 ≤ LimbArray.w A

        The limbs have at least 32 bits, for the multipliers of the interpolations, up to 9¹⁰.

      • zeros : Nat → A

        An array of n zero limbs.

      • size_zeros (n : Nat) : LimbArray.size (zeros n) = n
      • val_get_zeros (n i : Nat) : LimbArray.val A (LimbArray.get (zeros n) i) = 0

        D + S v for a limb v: addMulInto d o len s so sl v.

      • subMulInto : A → Nat → Nat → A → Nat → Nat → Nat → A

        D - S v for a limb v: subMulInto d o len s so sl v.

      • subMulInto_spec (d : A) (o len : Nat) (s : A) (so sl v : Nat) : o + len ≤ LimbArray.size d → v < 2 ^ LimbArray.w A → LimbArray.valAt s so sl * v ≤ LimbArray.valAt d o len → Writes (subMulInto d o len s so sl v) d o len ∧ LimbArray.valAt (subMulInto d o len s so sl v) o len = LimbArray.valAt d o len - LimbArray.valAt s so sl * v

        D - S v for a limb v, with S another window of the same array, disjoint from D: subMulWin d o len so sl v.

        The values at 1, 2 and 3 of the three pieces of k limbs of X, in the windows of k + 1 limbs at 0, k + 1 and 2 (k + 1) of a new array: evals3 x xo xl k.

        A chain D₁ - v D₂, D₂ - v D₃, D₃ - v D₄ of four disjoint windows of len limbs of d, each from the old value of the next, in one pass: sub3Chain d o₁ o₂ o₃ o₄ len v.

      • shlTop : A → Nat → Nat → A

        D 2^(w - 1), wrapped: an even D that fits in all but the top limb ends up halved in the limbs from the second on.

      • shlTop_spec (d : A) (o len : Nat) : o + len ≤ LimbArray.size d → Writes (shlTop d o len) d o len ∧ LimbArray.valAt (shlTop d o len) o len = LimbArray.valAt d o len * 2 ^ (LimbArray.w A - 1) % 2 ^ (LimbArray.w A * len)

      • shr_spec (d : A) (o len s : Nat) : o + len ≤ LimbArray.size d → 0 < s → s < LimbArray.w A → Writes (shr d o len s) d o len ∧ LimbArray.valAt (shr d o len s) o len = LimbArray.valAt d o len / 2 ^ s
      • divExact : A → Nat → Nat → Nat → A

        D / q for an odd limb q that divides D: divExact d o len q.

      • divExact_spec (d : A) (o len q : Nat) : o + len ≤ LimbArray.size d → q % 2 = 1 → q < 2 ^ LimbArray.w A → LimbArray.valAt d o len % q = 0 → Writes (divExact d o len q) d o len ∧ LimbArray.valAt (divExact d o len q) o len = LimbArray.valAt d o len / q

        x + y in a new array of xl + 1 limbs: sum x xo xl y yo yl, for yl ≤ xl.

      • sum_spec (x : A) (xo xl : Nat) (y : A) (yo yl : Nat) : yl ≤ xl → LimbArray.size (sum x xo xl y yo yl) = xl + 1 ∧ LimbArray.valAt (sum x xo xl y yo yl) 0 (xl + 1) = LimbArray.valAt x xo xl + LimbArray.valAt y yo yl
      • mid : A → Nat → Nat → Nat → A → A

        The middle term of Karatsuba's method: with Z₀ in the 2 k limbs of d from o on and Z₂ in the n - 2 k limbs above, and t = Z₀ + Z₁ + Z₂ in the 2 k + 2 limbs of t, writes Z₀ + 2^(w k) Z₁ + 2^(2 w k) Z₂ into the n limbs from o: mid d o k n t.

      • mid_spec (d : A) (o k n : Nat) (t : A) : o + n ≤ LimbArray.size d → Writes (mid d o k n t) d o n ∧ ∀ (Z₁ : Nat), LimbArray.valAt t 0 (k + k + 2) = LimbArray.valAt d o (k + k) + Z₁ + LimbArray.valAt d (o + (k + k)) (n - (k + k)) → LimbArray.valAt d o (k + k) + 2 ^ (LimbArray.w A * k) * Z₁ + 2 ^ (LimbArray.w A * (k + k)) * LimbArray.valAt d (o + (k + k)) (n - (k + k)) < 2 ^ (LimbArray.w A * n) → LimbArray.valAt (mid d o k n t) o n = LimbArray.valAt d o (k + k) + 2 ^ (LimbArray.w A * k) * Z₁ + 2 ^ (LimbArray.w A * (k + k)) * LimbArray.valAt d (o + (k + k)) (n - (k + k))
      • mulBase : A → Nat → A → Nat → Nat → A → Nat → Nat → A

        x y into the xl + yl limbs of d from o on: mulBase d o x xo xl y yo yl.

      • mulBase_spec (d : A) (o : Nat) (x : A) (xo xl : Nat) (y : A) (yo yl : Nat) : o + (xl + yl) ≤ LimbArray.size d → Writes (mulBase d o x xo xl y yo yl) d o (xl + yl) ∧ LimbArray.valAt (mulBase d o x xo xl y yo yl) o (xl + yl) = LimbArray.valAt x xo xl * LimbArray.valAt y yo yl
      • sqrBase : A → Nat → A → Nat → Nat → A

        x² into the 2 xl limbs of d from o on: sqrBase d o x xo xl.

      • sqrBase_spec (d : A) (o : Nat) (x : A) (xo xl : Nat) : o + (xl + xl) ≤ LimbArray.size d → Writes (sqrBase d o x xo xl) d o (xl + xl) ∧ LimbArray.valAt (sqrBase d o x xo xl) o (xl + xl) = LimbArray.valAt x xo xl * LimbArray.valAt x xo xl
