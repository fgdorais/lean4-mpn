    Steps of the Toom methods #

    The passes of ToomOps as equations on values, for the interpolations: each takes the value Q of the window it writes and gives the value V of the result from an equation Q = … + V, so that a chain of them needs no subtraction or division on Nat. Then the recombination: clearing the middle of the result and adding a coefficient at its place.

    source
    theorem MPN.Toom.lt_limb {A L : Type} [LA : LimbArray A L] [R : ToomOps A L] {m : Nat} (h : m < 2 ^ 32) :
    m < 2 ^ LimbArray.w A

    A multiplier m < 2³² is a limb.

    Passes by values #

    The passes on windows of one array, which return what they leave unchanged (Writes), so that the values of the other windows carry over; subMulWin_val subtracts a window of the same array, sub3W_val and sub3ChainW_val write three windows in one pass.
