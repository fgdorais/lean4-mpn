    Arrays of limbs #

    LimbArray A L describes arrays A of limbs L of w bits: their size, their limbs, and the value of a limb. valAt a lo n is the natural number whose little-endian base 2ʷ limbs are a[lo], …, a[lo + n - 1]; its lemmas hold for limbs of any width. main32 and main64 instantiate the class on their arrays of 32-bit and 64-bit limbs, and their own valAt is this one.

      The width of a limb in bits.

    • w_pos : 0 < w A
    • size : A → Nat

      The number of limbs of an array.

    • get : A → Nat → L

      Limb i of an array, which is zero past its end.

    • val : L → Nat

      The value of a limb.

    • val_lt (x : L) : val A x < 2 ^ w A
    • set : A → Nat → Nat → A

      Sets limb i of an array to v % 2ʷ, if i is within it.

    • size_set (a : A) (i v : Nat) : size (set a i v) = size a
    • get_set_ne (a : A) (i v j : Nat) : j ≠ i → get (set a i v) j = get a j
    • val_get_set_self (a : A) (i v : Nat) : i < size a → val A (get (set a i v) i) = v % 2 ^ w A

          The compiled value #

          valAt goes one limb at a time, multiplying a growing Nat at each, which takes quadratic time. Its compiled twin splits the limbs in halves and joins them with a shift, which Nat does in linear time, so that the value takes O(n log n). @[csimp] makes the compiler use it.
