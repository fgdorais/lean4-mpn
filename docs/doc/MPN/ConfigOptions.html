    Thresholds as options #

    The thresholds of a width are the Nat fields of a structure C with defaults, such as MPN.W64.Config. declare_config_options C pfx registers an option pfx.f : Nat for each of them, with the default of the structure and the field's docstring as its description, and mpn_config% C pfx is the C that the options in effect give: the fields whose options are set, and the defaults of the others. The proof fields of C keep their default tactics, so a value that breaks one is an error when mpn_config% elaborates. A module cannot read the options it registers, so mpn_config% goes in a module that imports the one with declare_config_options.
