    Finite sums #

    sumRange f n = f 0 + ⋯ + f (n - 1) on natural numbers, with the lemmas that the column sums of schoolbook products and the inversion of the FFT need: shifting, splitting, reflecting and swapping sums, and sums modulo F.

    source
    def MPN.sumRange (f : Nat → Nat) :
    Nat → Nat

    f 0 + f 1 + ⋯ + f (n - 1).
