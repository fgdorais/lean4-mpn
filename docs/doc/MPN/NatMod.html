    Congruences of natural numbers #

    Lemmas about a % F = b % F for the arithmetic modulo the Fermat numbers of the FFT: -1 to odd powers and squared, cancelling an addition, and the translation to divisibility in Int, where differences are available.

    source
    theorem MPN.dvd_pow_odd_add_one (y u : Nat) (hu : u % 2 = 1) :
    y + 1 ∣ y ^ u + 1

    y + 1 divides yᵘ + 1 for an odd u.

    source
    theorem MPN.pow_odd_mod {y F u : Nat} (hy : (y + 1) % F = 0) (hu : u % 2 = 1) :
    (y ^ u + 1) % F = 0

    -1 to an odd power is -1, modulo F.

    source
    theorem MPN.sq_of_neg_one {y F : Nat} (hy : (y + 1) % F = 0) :
    y * y % F = 1 % F

    The square of -1 is 1, modulo F.

    source
    theorem MPN.mod_cancel_add {a b c F : Nat} (hF : 0 < F) (h : (a + c) % F = (b + c) % F) :
    a % F = b % F

    Adding the same number to both sides of a congruence modulo F > 0 can be undone.

    source
    theorem MPN.mod_eq_iff_dvd {a b F : Nat} :
    a % F = b % F ↔ ↑F ∣ ↑a - ↑b

    A congruence of natural numbers is a divisibility of their difference in Int.

    source
    theorem MPN.dvd_mod_sub (x F : Nat) :
    ↑F ∣ ↑(x % F) - ↑x
