    Natural numbers #

    GNat A is a natural number as a machine word below 2⁶⁴ and as trimmed limbs A above, so that each natural number has exactly one representation: toNat and ofNat are inverse bijections between GNat A and Nat, and equality, comparison and hashing work on the representation.

    The arithmetic takes a fast path on words when both numbers are small, checking for overflow, and otherwise works on limbs with the operations of the instance of NatLimbs A, which are whole-number operations on trimmed arrays with their values. Every operation is proved correct against Nat. main32 and main64 instantiate it on their arrays of 32-bit and 64-bit limbs as MPN.Nat, and add the square root by their own algorithms; the greatest common divisor is in MPN.NatGcd.

    Lean's own Nat stores small values in the pointer itself; a type defined in Lean cannot, so a small GNat is a heap object holding its word, which costs an allocation per result.

    Type

    Whole-number operations on trimmed arrays of limbs A, with their values: each takes trimmed arrays and returns a trimmed array, the representation of each number being unique.

      The value of an array.

      Whether an array is trimmed: no zero limb on top.

    • decEq : DecidableEq A

      Equality of arrays.

    • hash : A → UInt64

      A hash of an array.

    • ofNat : Nat → A

      The array of a natural number.

    • trimmed_ofNat (n : Nat) : trimmed (ofNat n) = true
    • val_ofNat (n : Nat) : val (ofNat n) = n
    • ofWord : UInt64 → A

      The array of a word.

    • trimmed_ofWord (w : UInt64) : trimmed (ofWord w) = true
    • val_ofWord (w : UInt64) : val (ofWord w) = w.toNat
    • wide : UInt64 → UInt64 → A

      The array of lo + 2⁶⁴ hi, for hi ≠ 0.

    • wide_spec (lo hi : UInt64) : hi ≠ 0 → trimmed (wide lo hi) = true ∧ val (wide lo hi) = lo.toNat + 2 ^ 64 * hi.toNat
    • fits : A → Bool

      Whether a trimmed array is below 2⁶⁴.

    • fits_iff (a : A) : trimmed a = true → (fits a = true ↔ val a < 2 ^ 64)
    • toWord : A → UInt64

      The word of an array below 2⁶⁴.

    • val_toWord (a : A) : trimmed a = true → val a < 2 ^ 64 → (toWord a).toNat = val a
    • add : A → A → A
    • trimmed_add (a b : A) : trimmed (add a b) = true
    • val_add (a b : A) : val (add a b) = val a + val b
    • sub : A → A → A

      a - b, for b ≤ a.

    • trimmed_sub (a b : A) : trimmed (sub a b) = true
    • val_sub (a b : A) : val b ≤ val a → val (sub a b) = val a - val b
    • lt : A → A → Bool

      Whether a < b.

    • lt_iff (a b : A) : lt a b = true ↔ val a < val b
    • mul : A → A → A
    • trimmed_mul (a b : A) : trimmed (mul a b) = true
    • val_mul (a b : A) : val (mul a b) = val a * val b
    • sqr : A → A
    • trimmed_sqr (a : A) : trimmed (sqr a) = true
    • val_sqr (a : A) : val (sqr a) = val a * val a
    • div : A → A → A

      a / b, and 0 for b = 0.

    • trimmed_div (a b : A) : trimmed (div a b) = true
    • val_div (a b : A) : val (div a b) = val a / val b
    • mod : A → A → A

      a % b, and a for b = 0.

    • trimmed_mod (a b : A) : trimmed (mod a b) = true
    • val_mod (a b : A) : val (mod a b) = val a % val b

      a / b for a nonzero word b.

    • val_divW (a : A) (b : UInt64) : b ≠ 0 → val (divW a b) = val a / b.toNat
    • modW : A → UInt64 → UInt64

      a % b for a nonzero word b.

    • val_modW (a : A) (b : UInt64) : b ≠ 0 → (modW a b).toNat = val a % b.toNat

      a 2ⁿ.

    • trimmed_shl (a : A) (n : Nat) : trimmed (shl a n) = true
    • val_shl (a : A) (n : Nat) : val (shl a n) = val a * 2 ^ n
    • shr : A → Nat → A

      ⌊a / 2ⁿ⌋.

    • trimmed_shr (a : A) (n : Nat) : trimmed (shr a n) = true
    • val_shr (a : A) (n : Nat) : val (shr a n) = val a / 2 ^ n
    • land : A → A → A
    • trimmed_land (a b : A) : trimmed (land a b) = true

    • val_lor (a b : A) : val (lor a b) = val a ||| val b
    • xor : A → A → A
    • trimmed_xor (a b : A) : trimmed (xor a b) = true
    • val_xor (a b : A) : val (xor a b) = val a ^^^ val b
    • log2 : A → Nat

      ⌊log₂ a⌋, from the top limb.

    • log2_eq (a : A) : trimmed a = true → 2 ^ 64 ≤ val a → log2 a = (val a).log2
    • toDecimal : A → String

      The decimal digits.

    • toDecimal_eq (a : A) : trimmed a = true → toDecimal a = (val a).repr
    • ofDecimal : String → A

      The value of a string of decimal digits, for a string that String.isNat accepts.

    • ofDecimal_spec (s : String) : s.isNat = true → trimmed (ofDecimal s) = true ∧ s.toNat? = some (val (ofDecimal s))

                Results of two words #

                A sum or product of two words can overflow 64 bits. mulWide computes the whole product of two words from the four products of their halves, and wideOf makes the GNat of a two-word number directly, as one array (NatLimbs.wide), where the general arithmetic would make an array for each word first.
